# Data Sources

Large scientific inputs are obtained from their upstream providers and passed to commands by path.

Required resource families are:

- UniProtKB, UniRef50 and UniProt identifier mappings;
- GOA annotations and Gene Ontology OBO files;
- CAFA3 sequences, annotations and assessment mappings;
- 80/30 and 30/30 clique assignments;
- ProtT5, PubMedBERT and ESM-IF1 weights, AlphaFold structures and STRING PPI data;
- upstream PFP, CAFA assessment and MMseqs2 installations.

See [current releases](current_releases.md) for the temporal benchmark sources.
